# Техническое задание

## Функционал мастера:
1. Создание новых учеников
2. Создание задач для ученика
3. Размещение материалов для ученика (Задача без ответов)
4. Проверка ответов ученика (комментарий + статус: Решено/Доработать)
5. Быстрый поиск заданий с непроверенными ответами
6. Быстрый поиск заданий без ответов
7. Быстрый поиск всех заданий, закреплённых за учеником

## Функционал ученика:
1. **Вход по токену** (`POST /auth/login`)
2. Отображение всех заданий и материалов, которые мастер задал ученику
3. Создание ответа, просмотр комментариев к ответу и отображение статуса

---

## API Endpoint'ы

### Auth
- `POST /auth/login` — вход в аккаунт по токену

### Master/User
- `POST /master/user/create` — создание ученика
- `POST /master/user/delete` — удаление ученика

### Master/Task
- `POST /master/task/create` — создание задачи
- `GET /master/task` — получение задач (с фильтрацией)
- `PATCH /master/task` — обновление задачи
- `POST /master/task/delete` — удаление задачи

### User/Answer
- `POST /user/answer` — создание ответа
- `GET /user/answer` — получение ответов
- `PATCH /user/answer` — обновление ответа
- `DELETE /user/answer` — удаление ответа

### File
- `POST /file/image` — загрузка изображения
- `DELETE /file/image` — удаление изображения
- `POST /file/file` — загрузка файла
- `DELETE /file/file` — удаление файла

## Утилиты

### Создание мастера (скрипт)

Для ручного создания мастера используйте скрипт `create_master.py`:

```bash
cd backend
python create_master.py <token> <full_name>
```

**Примеры:**

```bash
# Создать мастера с токеном "admin" и именем "Администратор"
python create_master.py admin "Администратор"

# Создать мастера с токеном "teacher1" и именем "Иван Петров"
python create_master.py teacher1 "Иван Петров"
```

**Что делает скрипт:**
1. Проверяет, не существует ли пользователь с таким токеном
2. Создаёт пользователя с `is_master=True`
3. Выводит информацию о созданном мастере

**После создания:**
- Используйте указанный токен для входа через `POST /auth/login`
- Мастер может создавать учеников через `/master/user/create`

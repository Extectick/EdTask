# 📝 Скрипты для работы с БД

## 🎓 add_master.py — Добавить учителя

### Использование:

```bash
cd backend
python data/add_master.py <name> <full_name>
```

### Примеры:

```bash
# Добавить мастера
python data/add_master.py ivanov_mp "Иванов Иван Петрович"

# Добавить ещё одного
python data/add_master.py petrova_ms "Петрова Мария Сергеевна"
```

### Параметры:
- `name` — уникальный токен/логин (используется для входа)
- `full_name` — полное имя для отображения в интерфейсе

---

## 👨‍🎓 add_user.py — Добавить ученика

### Использование:

```bash
cd backend
python data/add_user.py <user_id> <full_name> [master_token]
```

### Примеры:

```bash
# Добавить ученика без прикрепления к мастеру
python data/add_user.py abs#123 "Алексеев Алексей"

# Добавить ученика и прикрепить к мастеру
python data/add_user.py user#456 "Борисов Борис" ivanov_mp
```

### Параметры:
- `user_id` — уникальный токен/логин ученика
- `full_name` — полное имя для отображения
- `master_token` — (опционально) токен мастера для прикрепления

---

## 🔐 Токены для входа

После добавления пользователей используйте их токены для входа:

| Роль | Токен | Страница |
|------|-------|----------|
| Мастер | `ivanov_mp` | `/master/students` |
| Ученик | `abs#123` | `/client/tasks` |

## 🛠 Отладка

Если скрипт не работает:

1. **Проверь что зависимости установлены:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Проверь путь к БД:**
   - Файл БД: `backend/data/edu_system.db`
   - Должен существовать после первого запуска сервера

3. **Закрой сервер перед запуском скрипта** (опционально):
   ```bash
   # Останови uvicorn (Ctrl+C)
   # Запусти скрипт
   python data/add_master.py ...
   # Запусти сервер заново
   uvicorn main:app --reload
   ```
